# 2048: Tech Evolution — Development Spec

## Game Identity
- **Route**: `/arcade/2048/`
- **Type**: Solo (endless, score-chasing)
- **Time**: 5–15 minutes per session
- **Replay Guarantee**: Random tile spawns create a unique board state on every play — classic 2048 mechanics are inherently unrepeatable

---

## Core Gameplay Loop

1. **Start**: A 4x4 grid with two initial tiles (value 2 or 4, random positions).

2. **Each Turn**: Player swipes or presses arrow keys (Up/Down/Left/Right).
   - All tiles slide as far as possible in that direction.
   - Adjacent tiles with the same value merge into a single tile with doubled value.
   - A new tile (90% chance value 2, 10% chance value 4) spawns in a random empty cell.
   - Score increases by the value of each merge.

3. **Theme**: Each tile value maps to a computing era:

| Value | Label | Color |
|-------|-------|-------|
| 2 | Punch Card | `#fef3c7` (cream) |
| 4 | Floppy Disk | `#fde68a` (light amber) |
| 8 | Dial-up | `#fcd34d` (amber) |
| 16 | CRT Monitor | `#fbbf24` (gold) |
| 32 | Server Rack | `#f59e0b` (deep gold) |
| 64 | Ethernet | `#d97706` (amber-600, brand) |
| 128 | WiFi Router | `#b45309` (brown amber) |
| 256 | Smartphone | `#92400e` (dark amber) |
| 512 | Cloud VM | `#3b82f6` (blue) |
| 1024 | Container | `#8b5cf6` (purple) |
| 2048 | Quantum AI | `#ec4899` (pink, with glow) |
| 4096+ | Singularity | `#ef4444` (red, pulsing glow) |

4. **Game Over**: When no moves are possible (no empty cells AND no adjacent same-value tiles).

5. **Win Detection**: Reaching the 2048 tile triggers a "You evolved to Quantum AI!" celebration, but the player can continue playing past 2048.

## Technical Requirements

### Component Structure
```
src/components/arcade/TechTiles2048/
├── TechTiles2048.tsx         # Root: game board + score + controls
├── GameBoard.tsx             # 4x4 grid rendering with tile animations
├── GameEngine.ts             # Pure logic: slide, merge, spawn, game-over detection
├── Tile.tsx                  # Individual tile with label, color, merge/spawn animations
└── constants.ts              # Tile theme map (value → label + color), scoring
```

### Game Engine (`GameEngine.ts`)
Pure functional state machine with zero side effects:

```typescript
interface GameState {
  grid: number[][];        // 4x4 array of tile values (0 = empty)
  score: number;
  bestScore: number;
  isGameOver: boolean;
  hasWon: boolean;         // True when 2048 tile is reached
  lastMerged: [number, number][]; // Positions that merged this turn (for animation)
  lastSpawned: [number, number] | null; // Position of newly spawned tile
}

function slide(state: GameState, direction: 'up' | 'down' | 'left' | 'right'): GameState
function canMove(state: GameState): boolean
function spawnTile(state: GameState): GameState
function newGame(): GameState
```

### Input Handling
- **Desktop**: Arrow keys (Up/Down/Left/Right). Also support WASD.
- **Mobile**: Touch swipe detection with minimum 30px threshold to distinguish from taps.
  ```typescript
  // Swipe direction detection:
  // 1. Record touchStart position.
  // 2. On touchEnd, calculate dx/dy.
  // 3. If |dx| > |dy| && |dx| > 30px → horizontal swipe (left if dx<0, right if dx>0).
  // 4. Else if |dy| > 30px → vertical swipe.
  ```
- Prevent default scroll behavior during gameplay to avoid accidental page scrolls on mobile.

### Animations
- **Slide animation**: Tiles translate from old position to new position over 120ms using CSS `transform: translate()` with `transition: transform 120ms ease-out`.
- **Merge animation**: Merged tile briefly scales to 1.15x then back to 1x over 150ms (`@keyframes merge-pop`).
- **Spawn animation**: New tile scales from 0 to 1 over 100ms (`@keyframes spawn-in`).
- **Game Over overlay**: Translucent dark overlay fading in with "Game Over" text and final score.

### Performance Mandates
- Use CSS transforms for all animations (GPU-composited, no reflows).
- Grid state updates must be synchronous and under 1ms.
- Touch event handling must use `{ passive: false }` to call `preventDefault()` without jank.
- Total bundle under 15KB gzipped (this is a simple game — keep it tight).

### Styling
- Grid background: `var(--surface-sunken)` with 12px gap between cells.
- Empty cells: `var(--blue-200)` (light mode) / `var(--blue-800)` (dark mode).
- Tile font: `var(--font-mono)`, bold, with text size scaling down for larger numbers.
- Tiles above 512 get a subtle CSS `box-shadow` glow in their theme color.
- The 2048 "Quantum AI" tile gets a rainbow-shimmer CSS animation.
- Score display: Large monospace counter at top-right, "BEST" label with localStorage high score.
- Responsive: Grid fills available width on mobile, max 400px on desktop.

### Storage & Sharing
- `storage.setHighScore('2048-tech', score)`.
- Persist in-progress game to localStorage so refreshing doesn't lose the board:
  ```typescript
  localStorage.setItem('ds_arcade_2048_state', JSON.stringify(gameState));
  ```
