# How to be a Better Frontend developer

Whether you are new to frontend development or simply beginning your career on the frontend then this article is for you.

1. Where to Start
The starting stage of learning is very important this is the place where you can put full effort to learn something to the core. if you put your 100% into learning the basics it will help you in the long term.

In Frontend development also the basic things which you have to master are HTML, CSS & Javascript. Without this, you can’t understand how webpage design and scripts work. Investing some time to understand the concepts of basic things will help you to build many complex things later.

I recommend these below websites to learn the basics of HTML, CSS, & Javascript for free,

freecodecamp.org
w3schools.com
https://developer.mozilla.org/ (Official documentation for web technologies)
2. Always Practice
Effective practice means actually going in the direction you want to go. That means setting goals and actively pursuing them. Practice helps you to gain experience in the skills you working on.

Here few project ideas you can work on once you learn enough the basic of frontend,

Build a Clone Website – Since you are new it helps you to focus on one goal that you have to replicate the design nothing more you can learn from simple design to complex design fundamentals.
Build a Calculator – Build a beautiful calculator layout using HTML & CSS and then try to add the functionalities using Javascript.
Build a Portfolio Site – it is one of the best ideas to create our own resume as a website so that you can showcase your skills to others.
Build Weather App – you can use Javascript fetch API to access third-party resources with any free weather API providers.
Build UI Components – Try to build the UI components like Dropdown, Select, Accordion, Carousel, etc from the scratch.
3. Use tools to enhance your development
Some frontend tools which help you to speed up your development process are,

VS Code – One of the best code editor for frontend development.
VS Code Extensions – Extensions help you to improvise the coding structures, quality, and more.
Online Code editors for small design components Codepen, Jsbin, and for large web applications StackBlitz, CodeSandbox.
GIT / Github – use git to control different versions of your projects.
4. Frontend Frameworks – When to Start?
Some newcomers start their career directly with any one of the frontend frameworks like Angular, React, or Vue. But I suggest do not go directly on frameworks it will narrow down your learning curve on frontend development and you don’t know how things are works under the hood in CSS and Javascript.

Think like the HTML, CSS & Javascript are like an Ocean and Frameworks are like Ships that help you sail easily. But if you know the ocean you can do whatever you want.

Here’s another example,

if you know Angular only then you can do Angular-based web applications, If you know React then you can do React-based applications. But if you know Javascript you can able to build your own framework like Angular/React/Vue.

5. Build SPA with Angular/React/Vue
Once you are good at Javascript and learned one of the frameworks then give yourself to try building Single Page Application(SPA). It will make you stronger and give you some incredible experience.

Here are some SPA idea’s that you can build,

Build an E-commerce web App like Amazon or Flipkart.
Build a Movie Ticket Booking App.
Build a Quiz App.
6. What’s Next!
Every year there is a new frontend framework coming and some of them became very popular, So when it comes to frontend frameworks you can’t stop learning! you need to keep updated in this fast-growing world but don’t worry as I mentioned earlier every JS framework is based on Javascript only if you know Javascript you can adapt it easily.

Once you are good at building SPA then you can start contributing open source projects from GitHub. Open Source contribution is contributing our work to other projects. it is the best way to improve your coding skills and experience new challenges.
