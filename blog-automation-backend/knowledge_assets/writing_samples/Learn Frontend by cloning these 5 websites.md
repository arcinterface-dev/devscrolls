# Learn Frontend by cloning these 5 websites

There are tons of resources available on the internet if you want to learn front-end technologies. There are two approaches you can take based on your interest and available time to learn these skills.

Some people prefer to take “learn by reading/visualizing” each and every concept step by step, which helps you to understand the language’s core nature of the language but this approach will take the long path.
On the other hand, If you are interested in taking the shortest path then you have to take the “learn by doing” approach where you can pick a goal on what you want to build and start googling on that without knowing the language concept of how to do it. Interesting right?
But remember, “Learn by doing” approach requires some googling skills, People with good googling skills always find what they searching for.

– It’s me from the experience 😉
If you feel like the second approach is your type then this article is for you.

Let’s Start with a basic website layout to advance level web design trends 😎

1. Wikipedia
Difficulty Level: Easy

If you are new to frontend development and wanted to learn some basics of HTML & CSS then you can start with Wikipedia by cloning.

Wikipedia is the best free online encyclopedia where one can find information on anything about everything. Wikipedia doesn’t have many functionalities on its sites like Javascript events and Animations but still, it is built with very good HTML structure and minimum CSS design.

By cloning this site you can learn concepts like:-

HTML:

Basic HTML tags,
HTML Tables,
How to use Image tags and Anchor links with different attributes,
And more, There are many hidden HTML concepts you can learn by cloning this website.
CSS:

Learn about basic styling,
Display property (inline, inline-block, block): you will learn when and where to use these different display properties,
CSS float property – You can build an entire website layout with float & width properties alone without using flexbox or gird and you will learn how to use float property by cloning Wikipedia which is built with float property for layout.
Link: https://en.wikipedia.org/wiki/Main_Page

2. Youtube
Difficulty Level: Easy

Once you have learned the basic web page structuring and stylings, You can build some other layouts like flex & grid.

Youtube is entirely built with a “flex” layout, By cloning this you can understand how a flex layout works. In general Flex, layout helps us to distribute the spaces between other sibling elements and help us to align the contents in the way the webpage needs.

Compared with other layout properties “flex” is very easy and powerful to build a website like youtube.

By cloning this site you can learn concepts like:-

Semantic HTML elements like main, and aside tags, and when to use them.
CSS Position properties and how to use them,
CSS Flexbox layout.
Basic animations like transition, transform,
Basic Javascript events.
Link: https://www.youtube.com/

3. Amazon/Flipkart
Difficulty Level: Medium

Let’s dive into some larger web applications like E-commerce.

E-commerce websites like Amazon, and Flipkart has a bunch of UI components that work together to make a whole nice user experience for the customer. you can learn different Layout concepts, Animations & Javascript events all together by cloning this website.

Things you can learn by cloning this site:-

HTML forms,
UI components like carousel, accordion, autocomplete, image preview plugin, etc.
Javascript forms handling, event binding, managing data across the site & sharing data from product page to cart page.
Link: https://www.amazon.in/ & https://www.flipkart.com/

4. Facebook
Difficulty Level: Hard

Facebook is one of the best online social media platforms which helps us to share information, find new people, and able to communicate with others. It’s also one of the large web applications that we could learn from by making a clone of it.

Facebook is built with React js on its client side. Which is one of the popular frontend frameworks these days. you can use the same React js or any other frameworks like Angular or Vue to clone Facebook.

Things you can learn by cloning this site:-

You can clone Facebook by simply using HTML, CSS & Javascript or you can try using frameworks at this stage so that you can learn more about frameworks,
Building Charts with the help of some third-party libraries,
Learn about component-based design,
You can learn Javascript advance concepts in this phrase like Promise, Async/Await, Fetch, etc.
You can learn about accessing third-party API resources on our webpage with the help of “Fetch API” in Javascript. Third parties like JSONPlaceholder help you to get some default random post data for your fake Facebook web app.
Link: https://www.facebook.com/

5. Apple
Difficulty Level: Hard

Have you ever seen apple’s product page before? Of course, you may be seen shopping or checking the new products as a customer but check again as a developer. Each product page has some unique style, the finest animation, motion graphics, etc. By cloning this page you can learn several CSS & Javascript concepts.

Once you entered into a product page like iPhone 14, You will find countless CSS & Javascript animations on each and every scroll. Scrolling this page makes you feel like a journey from start to end. This is the page where you will learn how to write dynamic CSS using javascript to make effective and wonderful animations.

Trust me! you will enjoy each and every section while cloning this page and the learnings are more.

Things you can learn by cloning this site:-

How to use CSS transform, transition, animations property,
Scrolling Animation, Micro Animation & many UI Components,
Javascript concepts like Intersection Observer, Scroll event, Video & Audio controls, and adding CSS from the Javascript file based on conditions.
Moreover, you will learn about design patterns, how to choose the right colors, typography, etc.
Link: https://www.apple.com/iphone-14/
