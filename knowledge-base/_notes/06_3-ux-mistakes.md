# 3 Common UX Mistakes Killing Good Design — Extraction Notes

## PDF Metadata
- **Title:** 3 Common UX Mistakes Killing Good Design
- **Authors:** Kamil Zieba & Jerry Cao, UXPin Inc., 2015
- **Page count:** 19 pages

## The 3 Named Mistakes
1. **Designing for yourself** (ego over user needs)
2. **Mistaking UX for UI** (polish ≠ usability)
3. **Asking users for too much information** (friction kills conversion)

## Mistake 1: Designing for Yourself (p. 5-8)

### Principle: Isolate passion from ego
"You're not out to prove anything... your only goal is to help the user." (p. 5)

### Practices to ground yourself
- Put yourself in user's shoes at every stage
- Build user journeys
- Build personas (reader, recruiter, scanner)
- Identify difficult UI parts and wireframe first
- Test on as many real devices as possible
- Minimum: moderated or unmoderated usability tests
- A/B test colors, buttons, text, images

### Time-box animations
Hero animations capture interest then **yield to content quickly**. Disable when `prefers-reduced-motion`. (p. 7)

## Mistake 2: Mistaking UX for UI (p. 9-12)

### UX ≠ UI
- UI = which buttons to press, where to go
- UX = how the overall design makes user **feel**
- UX is the umbrella over: visual design, IA, interaction design, usability, user research, content strategy

### "Dribbblisation of Design" warning
"Before you even touch Photoshop or Sketch, know your users — fears, goals, desires, behaviors, ambitions." (p. 10)

### Content-First Design Order
1. Content structure
2. Interaction design
3. Visual design

**"Content forms the foundation of all design, and it's what users actually care about."** (p. 12)

### Sitemaps before wireframes
"Always start with a site map so you can gauge the overall flow." (p. 11)

## Mistake 3: Asking for Too Much Information (p. 13-16)

### Users are lazy
More fields = less motivation. Duolingo's signup is the minimal model.

### Imaginary Landscapes evidence (p. 13-15)
- 11-field form → baseline
- 4-field form → **140% more signups**, ~120% rise in conversions
- **No impact on conversion quality**

### Define exactly the data you NECESSARY need (p. 15)
Every field needs documented rationale. Phone numbers risk unsolicited-contact fear.

### Expedia case
Removing one confusing "Company Name" field → **$12M sales upsurge.** (p. 16)

### There's no magic number — test
A/B test variants. Sales vs UX tension arbitrated by data.

## Further Tips (p. 17-18)

### KISS — Sculpture through subtraction
"Strip away everything that doesn't directly help users engage with content."

### Mobile-first navigation
Generous tap padding. ≥44-48px targets. Prevent encroachment.

### "Lost Traveler" mentality
Design each page as if first experience. Clear orientation (current location) + simple navigation (next step). Every page is potentially a landing page.

### All design rooted in psychology
Foster trust, inspire emotions. Read color psychology, personality in design, seductive interaction design.

### Tie-breaker rule
"When in doubt, ask yourself what the user would do, then slowly work your way back to the business goals." (p. 18)

## Key Quotes
1. "To be a successful designer, you must isolate passion from ego." (p. 5)
2. "UI is all about which buttons to press... UX is concerned with how the overall design makes the user feel." (p. 9-10)
3. "Content forms the foundation of all design, and it's what users actually care about." (p. 12)
4. "Users are lazy. The more forms you add, the less motivated users feel." (p. 13)
5. "There's no magic number... The only way to strike a balance is to test." (p. 16)
6. "Business goals might decide the destination, but user requirements must always steer the ship." (p. 18)
