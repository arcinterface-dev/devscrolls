# The Visual Storyteller's Guide to Web UI Design — Extraction Notes

## PDF Metadata
- **Title:** The Visual Storyteller's Guide to Web UI Design
- **Authors:** Jerry Cao & Cameron Chapman (Kamil Zięba contributing), UXPin Inc., 2015
- **Page count:** 68 pages

## Core Theses
1. Visuals are not decoration — they are the primary medium of meaning. Pictures = 6x more info than words; processed 60,000x faster than text.
2. Web storytelling is non-linear — narrative must be carried by visuals, not just prose.
3. Every site has beginning, middle, end. Intentionally map narrative arc.
4. Three image classes serve different jobs (iconic, symbolic, indexical).
5. **Authenticity beats polish** — custom > stock.
6. Interactivity serves the story, not the designer's ego.
7. Visual consistency ties the story together — image choices echo brand color/tone/audience.

## Principles

### 1. Picture Superiority (p. 11, 14)
Text alone: ~10% retention after 3 days. Text + relevant picture: ~65%. Pictures convey 6x more info.

### 2. Use Distinct, Non-Repetitive Imagery (p. 11-12)
Picture superiority disappears with similar images. Each visual anchors unique memory.

### 3. Maintain Cohesive Visual "World" (p. 12)
All imagery feels from "same world" — consistent illustration style, photo treatment, icon set.

### 4. Processed 60,000x Faster Than Text (p. 16)
~10 second decision window. Hero must communicate topic + value pre-cognitively.

### 5. Bullet Points Are NOT Pictures (p. 22)
Chunking helps cognitive load; rich imagery creates delight and recall.

### 6. Three Image Types — Iconic / Symbolic / Indexical (p. 24-31)
- **Iconic** = literal, instantly recognizable (trash can = delete)
- **Symbolic** = abstract metaphor (Windows logo, hamburger menu)
- **Indexical** = linked by association (thermometer = cold)

### 7. Navigation Must Be Iconic (p. 31-32)
Visitors should never wonder what an icon does. Hamburger menu only ~52% comprehension over 44 years.

### 8. Evoke Emotion via Indexical (p. 29-30)
Rain-soaked bicycle > crying face. Make users feel.

### 9. Illustrations Alternative to Photos (p. 37-38)
Excel for diagrams, flowcharts, abstract concepts. Cheaper than custom photography. Stock illustration too generic.

### 10. Don't Fear the Mascot (p. 40-41)
MailChimp Freddie. Sweaty hand on send, high-five on success. Emotional connection increases conversions.

### 11. Backgrounds Tell Story (p. 42)
Still, video, rotating. Reinforce or carry narrative.

### 12. HD Video Background Rules (p. 44-45)
- 10-30 second loops
- Sound off by default
- Load time critical (usability > wow)
- Static fallback for incompatible/low-bandwidth
- Genuinely HD source

### 13. Images Must Make Sense (p. 46-47)
Persona match? Color echo brand? Style consistent (sophisticated for sophisticated)?

### 14. Color Overlays for Cohesion (p. 49)
Subtle overlay tying images to palette unifies disparate sources.

### 15. Show People for Social Approval (p. 49)
Nielsen research: people photos remove barriers. Always show author photos.

### 16. Custom > Stock (p. 49)
Stock = generic. Custom illustrations cheaper than photo shoots. Differentiates from sea of identical tech blogs.

### 17. Palettes Carry Era and Emotion (p. 31)
Neon = 80s/90s. Pastels = 50s. Color alone shifts emotional context.

### 18. Match Expectations, Then Twist (p. 50)
Standard patterns for nav; reserve single signature element as "twist."

### 19. Story Length Matches Need (p. 52)
One image if one tells it. Twenty if twenty needed. Don't ration arbitrarily.

### 20. Make Users a Character (p. 52-54)
Personalize via input or real-time data. Tutorials prompting "Which framework do you use?" then re-framing examples.

### 21. Gamification via Cue-Routine-Reward (p. 55-58)
Reading progress, series checklists, contributor badges, completion animations.

### 22. Supplement Common Actions (p. 59-61)
Scrolling and clicking are unconscious. Add value with parallax, scroll-triggered reveals, hover-reveal.

### 23. 5-7 Word Hero Headline (p. 59) — HARD RULE
Plus high-res image fulfilling headline's promise.

### 24. Make Visuals Respond (p. 62)
Babel umbrella-cat. State animations on like/save/share, copy confirmation, search input transitions.

### 25. Easter Eggs for Right Audience (p. 63)
Dev audiences love discoverable details. Konami code, keyboard shortcuts, console messages.

### 26. Prioritize Visibility by Task Frequency (p. 64)
Critical tasks visible. Occasional tasks tucked in command palette.

### 27. Map Beginning-Middle-End (p. 17, 65-66)
Stimulus → engagement → resolution. Article: intro (hook) → body (engagement) → resolution (CTA).

### 28. Picture Superiority Is Age-Sensitive (p. 12-13)
More pronounced with age, cognitive impairments. Less pronounced in children. Pair visuals + text labels for accessibility.

### 29. Tone of Imagery Matches Content Intent (p. 39-40)
Even serious topics benefit from approachable visuals. Clean illustrative style for postmortems.

### 30. Define Site Persona via Mascot/Voice (p. 40)
Voice + visual character in branding guide. Surface in empty states, errors, success, micro-copy.

## Key Quotes
1. "Bullet points are not pictures." (p. 22)
2. "Visual information is processed up to 60,000 times faster than text information." (p. 16)
3. "The picture superiority effect says that visuals can convey up to six times more information than words alone." (p. 11)
4. "Before you know your story, know your user." (p. 10)
5. "Interaction design isn't an ornamental branch of web design. It is the core to allowing users to become part of the story you tell." (p. 67)
6. "Meet the user's expectations based on their prior experience, ensure your site appears consistent on all pages, then throw in your own creative twist to stay memorable." (p. 50)
